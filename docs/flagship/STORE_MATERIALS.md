# Store material draft — YouTube Focus Mode

## Short positioning

Choose your view. Keep your intention.

## Description

Popup view/session navigation; compact preset-first layout; up to ten named presets; reversible five-minute hiding pause with automatic return; keyboard timer correction; light and dark appearances.

Your data stays in this Chrome profile. No account or analytics service is required. Existing settings and records are retained on upgrade. Back up important data before changing browsers or removing an extension.

YouTube layouts vary. No ads, categorization or guaranteed distraction prevention claims. Voluntary locks can be bypassed by disabling the extension.

## Update notes

Version 3.2.0 introduces the redesigned interface and workflows described above. Existing product identity and permission scope are unchanged.

## Support

Report a reproducible problem at https://github.com/flegardev/YouTube-focus/issues. Include Chrome version, steps and redacted screenshots. Never attach browsing-history exports or private vehicle notes to a public issue.

## Screenshots

Use actual `docs/flagship/screenshots/` captures. Test data must be labeled illustrative; screenshots are not evidence of real personal activity or current vehicle availability. Existing icons remain in the package to preserve recognition.
