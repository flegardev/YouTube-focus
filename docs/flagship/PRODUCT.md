# YouTube Focus Mode — flagship redesign

Choose your view. Keep your intention.

## Delivered

Popup view/session navigation; compact preset-first layout; up to ten named presets; reversible five-minute hiding pause with automatic return; keyboard timer correction; light and dark appearances.

## Compatibility

Existing identity, permissions and legacy storage keys are preserved. New preferences use separate keys or additive vehicle fields. No tracking backend or telemetry was added.

## Candidate

Version 3.2.0. Rebuild with `npm ci` and `npm run package` in `extension`. Run `npm run test:extension` for legacy and new browser journeys. Fixtures use disposable Chromium profiles. They do not represent real participant research.

## Limits

YouTube layouts vary. No ads, categorization or guaranteed distraction prevention claims. Voluntary locks can be bypassed by disabling the extension.
