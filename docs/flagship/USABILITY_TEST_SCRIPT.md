# Five-person usability study

Recruit five genuine participants per product, or five people with relevant experience across the three tasks. Do not call automated journeys participants. Obtain consent for observation; recording is optional. Use disposable profiles and synthetic data, never require disclosure of private history. Provide compensation regardless of outcome and never in exchange for reviews.

## Session format — 25 minutes per product

1. Two minutes: ask how they currently solve the problem, without naming our features.
2. Show the installed toolbar icon. Ask what they think the product does.
3. Run the tasks below without coaching. Start timing when the task is read; stop on success, abandonment or three minutes. Record first action, completion, errors, requests for help and exact confusion points.
4. Ask for a 1–7 ease score after each task. Ask what they would remove, what they would miss, and whether they would keep the extension. Do not suggest a positive answer.
5. Offer an optional seven-day follow-up. Ask whether they used it again and why. Do not infer actual retention from stated intent.

## Garage tasks

- Save a supported listing and find it in your garage. Use the controlled fixture if live site access is restricted; mark that result as fixture-only.
- Compare two cars and explain which costs more and which details differ.
- Add a question for the seller and mark one purchase check complete.
- Put a car in a collection; search for it again.
- Export a backup, then import a prepared backup containing one duplicate and one new vehicle. Explain what changed.

## YouTube tasks

- Make YouTube suitable for learning while leaving comments available.
- Save that configuration under a name you will recognize.
- Temporarily restore the normal view, then restore your focus setup.
- Start a 25-minute voluntary focus session using only the keyboard.
- Explain the difference between hiding distractions, pausing and a voluntary lock.

## Logger tasks

- Start without interruptions and explain where data is stored.
- Read the weekly review and explain what is measured and what is missing.
- Choose a daily goal; explain the number used to calculate progress.
- Find where to correct a domain rule and exclude a private domain.
- Export a backup and identify how to delete records. Do not delete a participant's real data.

## Decision rules

Fix any data-loss, inaccessible primary action or misleading interpretation immediately. If two of five people fail the same primary task or interpret a metric incorrectly, revise and retest that task with new participants. Report observed counts rather than percentages implying statistical precision. A small usability study informs design; it does not prove market demand.
